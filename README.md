SportSphere Hub - IR3PIA Projekat
==================================

POKRETANJE:
1. Baza: mysql -u root sportsphere_db < sportsphere_db.sql
2. Backend: cd backend && mvn spring-boot:run (port 8080)
3. Frontend: cd frontend && npm install && ng serve (port 4200)
4. Otvori: http://localhost:4200
